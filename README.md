# Object-Oriented Programming Examples – CE-1102

This repository contains various examples and exercises related to Object-Oriented Programming (OOP), developed as part of the **CE-1102** course at the **Costa Rica Institute of Technology (TEC)**.

## 📘 About

The purpose of this repository is to demonstrate key OOP concepts using practical examples. These programs were written in **Python** and cover topics such as:

- Classes and Objects
- Encapsulation
- Inheritance
- Polymorphism
- Operator Overloading
- Dynamic Memory Management
- Abstract Classes and Virtual Methods
